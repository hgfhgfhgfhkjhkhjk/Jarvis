# Феникс (проект jarvis)

Локальный голосовой ассистент для Windows. Полностью офлайн, гибридное распознавание:
[Vosk](https://alphacephei.com/vosk/) (`vosk-model-small-ru`, ~45 МБ) непрерывно слушает
и ловит wake-слово, а команду точно расшифровывает **Whisper**. На машине с NVIDIA
автоматически берётся `large-v3-turbo` на GPU (int8_float16, ~1.5 ГБ VRAM,
~0.3–0.5 с на команду), без GPU — `small` на CPU. Синтез — локальный нейроголос
Piper (ru_RU ruslan/dmitri, ~0.2 с на CPU), фолбэк — системный Pavel.
Живёт в системном трее.

## Возможности

- Wake-слово **«Феникс»** — реагирует только после обращения. Имя выбрано
  бенчмарком (`scripts/wakebench.py`): Vosk распознаёт его 3/3, созвучных
  частых слов нет (кандидаты вроде «юпитер» или «сокол» отсеялись из-за
  «питер»/«около»). Ложные пробуждения дополнительно отсекает Whisper:
  если он не услышал в фразе ничего похожего на имя — команда игнорируется.
  Старое «джарвис» оставлено в конфиге как запасной вариант.
- Открытие/закрытие приложений: «Джарвис, открой стим», «закрой дискорд».
  Из коробки знает: Discord (дс), Telegram (тг), Steam, Dota 2, Claude Desktop,
  калькулятор, блокнот, проводник и др.
- **Любые установленные программы**: при старте индексируется меню «Пуск»,
  русская речь сопоставляется с английскими названиями через транслитерацию —
  «открой обс» → OBS Studio, «открой блендер» → Blender.
- «Закрой …» работает и по списку запущенных процессов (системные защищены от убийства).
- Открытие сайтов: «открой ютуб» (известные), «открой сайт хабр» (транслит + проверка
  DNS: habr.ru/.com/...), диктовка домена «хабр точка ру». Не нашёл — открывает поиск.
- Поиск с запросом: «загугли погоду», «найди на ютубе лофи», «открой гугл
  с поиском рецепт борща», «найди статью в википедии» (Гугл / Ютуб / Википедия).
- Скриншот: «Джарвис, сделай скриншот» → `Изображения\Screenshots`.
- Простые вопросы: время, дата, день недели, «как дела», «что ты умеешь».
- Свои команды в `config.json` — фраза → exe / ссылка / steam-URI.
- **Игры Steam**: библиотека индексируется по appmanifest — «запусти сабнатику»
  работает для любой установленной игры (запуск через steam://rungameid).
- **LLM-фолбэк и нативный Tool Calling**: команды, которые правила не поняли,
  разбирает локальная нейронка (Qwen2.5 1.5B/7B через [Ollama](https://ollama.com)).
  Поддерживается нативный **Function Calling (Tools API в Ollama)**: модель сама выбирает
  инструменты, строит цепочки вызовов и получает результаты выполнения Python-функций.
  Новые инструменты легко регистрируются через `@brain.tool`.
  Опционально: `winget install Ollama.Ollama && ollama pull qwen2.5:1.5b-instruct`;
  без Ollama просто выключается (`use_llm: false` — принудительно).
- **Глубокое управление Windows (UI Automation)**: интеграция `pywinauto`, `pyautogui`
  и `pyperclip` в модуле `jarvis/actions.py`:
  - Управление окнами: фокус, сворачивание, разворачивание, восстановление, закрытие, получение списка активных окон.
  - Управление мышью и клавиатурой: клики (ЛКМ, ПКМ, двойной), перемещение курсора, скролл, ввод любого текста (включая кириллицу) и шорткаты (`ctrl+s`, `alt+f4` и др.).
  - UI Automation: поиск и нажатие по элементам управления интерфейса Windows по имени окна и кнопки/контрола.
- **Цепочки действий**: «сделай скриншот и открой его», «открой стим и закрой
  дискорд» — фраза делится на шаги (или LLM возвращает план `steps`).
  Местоимение «его» указывает на последний созданный файл.
- **Музыка и медиа**: «включи музыку» — запущенному плееру жмётся play через
  его медиа-сессию (WinRT Media Control); если плеер закрыт — запускается
  и сворачивается после старта. «Пауза», «следующий трек», «громче/тише»,
  «без звука» — системные медиа-клавиши, работают с любым плеером.
- **Файлы и папки**: «открой загрузки», «что лежит на рабочем столе» (Феникс
  расскажет содержимое), «создай файл список покупок в документах»,
  «создай папку проекты», «что в ней».
- **Диалог**: всё, что не команда, уходит LLM с историей разговора — можно
  переспрашивать и уточнять; после ответа `dialog_window_sec` секунд Феникс
  слушает без wake-слова. Характер: спокойный, ироничный, «сэр».
- **Свой голос (клонирование)**: положите `voices/jarvis.wav` (10–30 с чистой
  речи — например, реплики Джарвиса из дубляжа) — XTTS-v2 на GPU заговорит
  этим голосом (см. voices/README.md). Без референса — быстрый Piper.
- В `custom_commands` можно задавать цепочки: `"steps": [{"action":"open_app",
  "target":"obs","minimized":true},{"action":"wait","seconds":3},...]`.

## Установка

```powershell
pip install -r requirements.txt
python -m jarvis
```

При первом запуске модель Vosk скачается автоматически в `models/`.

Запуск без окна консоли: `pythonw -m jarvis`.

### Exe и автозапуск

```powershell
python scripts/build_exe.py
```

Соберёт **`Феникс.exe`** в корне проекта — это лёгкий лаунчер (~7 МБ): он молча
запускает `pythonw -m jarvis` в папке проекта, без окна консоли, и не плодит
копии (мьютекс). Тяжёлые зависимости (torch, Whisper, XTTS) остаются в системном
Python — упаковывать их в один файл нет смысла (получились бы гигабайты).

Автозапуск — ярлык на `Феникс.exe` в папке `shell:startup`
(`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`). Отключить —
удалить ярлык оттуда или снять галку в «Диспетчер задач → Автозагрузка».

## Использование

Скажите «Феникс» и команду — вместе («Феникс, открой доту») или раздельно:
после «Феникс» ассистент ответит «Слушаю» и подождёт команду 8 секунд.

Меню в трее: пауза микрофона, скриншот, конфиг, журнал, выход.

## Свои команды

```json
"custom_commands": [
  {
    "phrases": ["запусти игру", "врубай катку"],
    "action": "steam://rungameid/570",
    "reply": "Запускаю Доту."
  },
  {
    "phrases": ["открой проект"],
    "action": "C:\\Users\\me\\Desktop\\project\\app.exe",
    "reply": "Открываю проект."
  }
]
```

Если встроенное приложение установлено в нестандартное место — путь указывается в
`app_paths`: `{"discord": "D:\\Apps\\Discord\\Discord.exe"}`.

## Технологии

| Компонент | Решение |
|---|---|
| Wake-слово (стриминг) | Vosk (Kaldi), модель `vosk-model-small-ru-0.22` |
| Расшифровка команды | faster-whisper (CTranslate2): GPU → `large-v3-turbo` int8_float16, CPU → `small` int8; `whisper_device`/`whisper_model` в конфиге, отключается `use_whisper: false` |
| GPU | CUDA-библиотеки из pip (`nvidia-cublas-cu12`, `nvidia-cudnn-cu12`), системная CUDA не нужна |
| Понимание команд | правила (мс) + LLM-фолбэк: Qwen2.5-1.5B-Instruct через Ollama REST (опционально) |
| Синтез речи | Piper TTS (ONNX, CPU): `tts_voice` ruslan/dmitri, скорость `voice_rate`; фолбэки WinRT/Pavel и SAPI. Прослушка: `python scripts/voicedemo.py` |
| Микрофон | sounddevice (PortAudio) |
| Трей | pystray + Pillow |

Всё работает локально, интернет нужен только для первого скачивания моделей.
Если GPU не завёлся — в логе будет причина и автоматический откат на CPU.

Важно для разработчиков:
- модель Whisper (CTranslate2) должна загружаться **до** первого вызова
  WinRT-синтеза, иначе процесс падает с access violation;
- ctranslate2 ищет `cublas64_12.dll` через `PATH` — `os.add_dll_directory`
  ему недостаточно (делается автоматически в `stt._enable_cuda_dlls`).
